Privacy policy

Content base rclone is a private tool used only by its owner to organize files in the owner's own Google Drive.

  • Google Drive data is accessed only to list files, read file metadata, create folders and move files within the same Drive.
  • No data is sold, shared with third parties or used for advertising.
  • Access tokens are stored only on the owner's computer with restricted permissions.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
